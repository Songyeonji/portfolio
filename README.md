# 송연지 포트폴리오

업무의 구조를 이해하고, 기술로 효율을 설계하는 개발자 — 웹 포트폴리오 + A4 PDF 동시 지원.

- **웹**: 반응형 단일 페이지 (프로젝트는 큰 썸네일 카드 + 상세 내용)
- **PDF**: 우측 상단 `PDF 다운로드` → 인쇄 창에서 **대상: PDF로 저장**
  - A4 한 장 = 한 섹션(표지·About / 지원동기·스킬 / 경력 / 프로젝트별 1장 / 학력·수상)으로 **페이지가 중간에 끊기지 않음**
  - 내용이 넘치면 그 페이지만 글자·썸네일을 자동으로 살짝 줄여 한 장에 맞춤
  - 텍스트가 살아있는 벡터 PDF라서 GitHub·YouTube·Velog 등 **링크가 PDF에서 바로 클릭됨**
  - 여백·머리글/바닥글은 자동으로 없음 (설정에서 '배경 그래픽'을 따로 켤 필요 없음)

## 편집 모드

1. 우측 상단 🔒 버튼 → 비밀번호 입력
2. 글자를 클릭해 바로 수정 (Ctrl+B 굵게, Shift+Enter 줄바꿈) · 이미지 위 `이미지 변경` · 목록마다 `+ 추가` / `×`
3. 섹션·프로젝트별 `숨기기`, 프로젝트 순서 `↑ ↓`
4. `A4 미리보기`로 PDF 페이지를 화면에서 확인 (넘치는 페이지는 빨간 테두리)
5. 저장
   - 수정 내용은 **이 브라우저에 자동 임시저장** → 바로 PDF 다운로드 가능
   - 사이트에 반영: `GitHub에 저장`(본인 Fine-grained 토큰, Contents 읽기/쓰기) 또는 `data.js 내보내기` 후 `js/data.js` 교체

비밀번호 없이 방문한 사람은 보기만 가능합니다(편집 비활성화).

> 정적 사이트라 비밀번호는 해시로만 들어있고 서버 검증은 없습니다. 방문자가 편집해도 그 사람 브라우저에만 남고, 사이트 원본을 바꾸려면 저장소 쓰기 권한(토큰)이 필요합니다.

### 비밀번호 바꾸기

```bash
node -e "console.log(require('crypto').createHash('sha256').update('새비밀번호').digest('hex'))"
```

출력된 값을 `js/app.js`의 `EDIT_PASSWORD_SHA256`에 넣으면 됩니다.

## 구조

```
index.html          화면 뼈대
css/style.css       웹 + A4(인쇄) 스타일
js/data.js          모든 내용 (편집 모드가 이 파일을 저장)
js/app.js           렌더링 · 편집 · PDF 맞춤 · GitHub 저장
assets/images/      프로필 · 프로젝트 썸네일
assets/uploads/     편집 모드에서 올린 이미지 (GitHub 저장 시 자동 생성)
```

## 로컬 실행 / 배포

```bash
py -m http.server 5173     # 또는 index.html 더블클릭
```

GitHub Pages: 저장소 **Settings → Pages → Deploy from a branch → `main` / `(root)`**.
